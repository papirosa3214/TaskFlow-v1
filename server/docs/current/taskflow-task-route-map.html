Маршрут задачи

Это неизменная схема жизненного цикла. Она не показывает текущую очередь: её состав меняется и выводится в отдельном статусном графе.

  1. 01

    Постановка

    Владелец создаёт карточку или утверждает черновик из чата.

  2. 02

    Контекст

    Карточка получает описание, шаги и нужные знания проекта.

  3. 03

    Назначение

    Владелец выбирает роль или делает задачу готовой к захвату.

  4. 04

    Работа

    Исполнитель берёт карточку, отмечает шаги и поддерживает heartbeat.

  5. 05

    Приёмка

    Результат уходит в review; владелец принимает работу, история остаётся в карточке.

Текущий статус: открыть живой снимок активных карточек.
