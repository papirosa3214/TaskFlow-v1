# Нативный iOS: шапка и фильтры экрана «Сегодня»

Этот документ фиксирует рабочую реализацию экрана `TodayScreen` в ветке
`native-app`. Перед изменениями шапки или фильтров прочитайте его полностью:
решение уже прошло визуальную проверку в iPhone Simulator и UI-тесты свайпов.

## Где находится код

- `native/Sources/Features/Today/TodayScreen.swift` — общая шапка, её слои,
  схлопывание при прокрутке и системные меню.
- `native/Sources/Features/Today/TodayListView.swift` — секции задач и передача
  координат следующего подзаголовка в шапку.
- `native/UITests/ViewsAndSwipesTests.swift` — настоящие `swipeUp()` и
  `swipeDown()` по экрану и строкам задач.

## Иерархия липкой шапки

Порядок слоёв в `TodayScreen` принципиален:

```text
3. headerChrome: «Вторник» / «1 сентября», подзаголовок, кнопки
2. headerFrost: единый полупрозрачный чёрный градиент
1. ScrollView: вся лента задач
```

`headerFrost` нельзя прикреплять отдельно к строке дня недели, подзаголовку или
компактной дате. Несколько подложек дают видимые серые полосы и стыки. Нельзя
также класть общий фон выше `headerChrome`: тогда он приглушает сами надписи.

В покое `headerChrome` имеет две строки:

1. День недели и кнопки действий.
2. Первый существующий раздел: `Ждут вас`, иначе `Просрочено`, иначе дата
   сегодняшнего дня.

При прокрутке вверх:

- шапка остаётся у верхнего края;
- большой день недели гаснет, в центре появляется полная дата;
- текущий подзаголовок поднимается на место большого дня недели;
- следующий подзаголовок из ленты заменяет текущий, когда доходит до шапки.

### Динамические границы секций

`Ждут вас` — только исходный первый подзаголовок. Он не публикует собственную
геометрическую метку и не может самопроизвольно вернуться после перехода на
`Просрочено`. Метки публикуют только последующие секции.

Каждая последующая секция сообщает свою координату напрямую через
`onGeometryChange`; общий массив `PreferenceKey` здесь запрещён. Внутри
`LazyVStack` он мог временно потерять header, поэтому визуально дошедшее до
шапки `Просрочено` не становилось текущим подзаголовком.

`TodaySectionTracker` принимает пересечение конкретной границы. При движении
вниз он разрешает только переход к той же или следующей секции, а при движении
назад — только к непосредственной предыдущей. Поэтому поздний callback от
старой секции не может откатить `1 сентября` на `Просрочено` или `Ждут вас`.
При смене фильтра, раскладки или состава секций активная метка явно сбрасывается.

При pull-down значение `headerPullDown` повторяет отрицательное смещение
`ScrollView`: вся шапка вместе с подложкой едет вниз вместе со списком. При
прокрутке вверх это значение равно нулю, поэтому шапка становится липкой.

## Фильтр — только системное меню

Кнопка `line.3.horizontal.decrease` реализована через SwiftUI `Menu`, как и
соседняя кнопка `…`. Это даёт один и тот же нативный стеклянный presentation,
анимацию, скругление и поведение вне зависимости от версии iPhone.

Верхний уровень меню содержит:

- `Проект` — вложенное системное меню с одиночным выбором;
- `Метка` — вложенное системное меню с одиночным выбором;
- `Исполнитель` — вложенное системное меню с одиночным выбором;
- `Показывать выполненные` — нативный `Toggle`;
- `Показывать в разделе` — вложенное меню с независимыми отметками проектов;
- `Сбросить фильтры` — destructive-команда, видимая только при активном
  фильтре.

Старый `TodayFilterSheetContent` и его полноэкранная/нижняя `.sheet` удалены.
Не возвращайте `.tfBottomSheet` для фильтра экрана «Сегодня»: это другой
паттерн интерфейса и визуально не совпадает с системным меню `…`.

## Инварианты

- У заголовков нет собственных цветных плашек.
- Между первым подзаголовком и первой задачей нет искусственного
  `Color.clear`-разделителя.
- Glow/затемнение — один слой между лентой и текстом шапки.
- Фильтр и меню вида — системные SwiftUI `Menu`.
- Выбранные фильтры хранятся в `TodayViewModel.filters`; меню не создаёт
  отдельную копию состояния.
- Границы секций передаются прямыми событиями `onGeometryChange`, без общего
  preference-массива виртуализированного списка.

## Проверка

После изменений обязательно проверить исходное, схлопнутое и pull-down
состояния в Simulator, затем запустить существующие тесты свайпов:

```bash
cd native
xcodegen generate --spec project.yml
xcodebuild test \
  -project TaskFlow.xcodeproj \
  -scheme TaskFlow \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -only-testing:TaskFlowUITests/ViewsAndSwipesTests \
  -derivedDataPath /private/tmp/taskflow-native-derived
```
