# Архитектура иерархии задач (Parent-Child)
**Дата:** 29.08.2026
**Автор:** Владелец / Antigravity

## Суть изменений
До 29.08.2026 система имела плоскую структуру задач, внутри которых были только микро-шаги (Subtasks/чекбоксы). Оркестратор имитировал делегирование, создавая новые задачи и вписывая в их описание текст: «Часть координационной задачи #ID».

Теперь в системе реализована полноценная иерархия задач через поле `parent_id`. 
Это позволяет Оркестратору брать глобальную задачу (Эпик/Проект) и дробить её на дочерние задачи, делегируя их разным агентам (Hermes, DeepSeek и др.) для параллельного выполнения.

## Как это работает технически

### 1. База данных
В таблицу `tasks` добавлена колонка `parent_id` (миграция `020_task_parent_id`). Она ссылается на `id` родительской задачи через `REFERENCES tasks(id) ON DELETE CASCADE`.

### 2. API (Бэкенд)
- **Общие списки чистые:** `GET /api/tasks` жестко отфильтровывает дочерние задачи (`WHERE t.parent_id IS NULL`). В Ежедневнике и Планировании владельца отображаются только задачи верхнего уровня, чтобы не засорять экраны.
- **Подгрузка дерева:** `GET /api/tasks/:id` (в функции `hydrateTask`) автоматически подтягивает массив дочерних задач (`children`), включая их статусы и исполнителей.
- **Создание:** `POST /api/tasks` теперь принимает параметр `parent_id`.

### 3. Инструменты агентов (MCP)
- В `mcp_server.py` инструмент `taskflow_create_task` научился принимать параметр `parent_id`.
- Промпт Оркестратора (`server/scripts/trigger.py`) переписан:
  - Он больше не вставляет текстовые связки в описание.
  - Он вызывает инструмент `taskflow_create_task` передавая `parent_id`.
  - Микро-шаги (аргумент `subtasks`) теперь используются исключительно как короткие чек-листы для проверки результата внутри дочерних задач.

### 4. Интерфейс (React UI)
В карточке задачи (`src/screens/TaskDetailScreen.tsx`) реализована система вкладок, которая превращает глобальную задачу в пульт управления проектом:
- **Вкладка "Чек-лист"**: Отображает классические шаги-чекбоксы (subtasks). Здесь находится личный план действий Оркестратора.
- **Вкладка "Команда"**: Появляется автоматически, если у задачи есть `children`. Отображает список дочерних задач с аватарками исполнителей, показывая в реальном времени, кто какую задачу делает и в каком она статусе (in_progress, review, blocked).
