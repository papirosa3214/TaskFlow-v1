# Нативный iOS: аудит плавности

Аудит выполнен на ветке `native-app` 1 сентября 2026 года. Цель — убрать
источники повторной раскладки и конкурирующие жесты, вызывавшие рывки при
прокрутке.

## Исправленные источники нагрузки

- `TodayComputation` теперь создаёт один снимок результатов за инициализацию,
  а не повторяет цепочки `filter`/`sort` при каждом обращении SwiftUI body.
- Форматтеры дат переиспользуются и защищены блокировкой вместо постоянного
  создания `DateFormatter` на горячих путях.
- Основные прокручиваемые экраны каталога, заметок, чата и планирования
  используют `LazyVStack`.
- Строки каталога больше не измеряют высоту через
  `GeometryReader + PreferenceKey`, вызывавшие дополнительный layout-pass.
- Горизонтальный свайп строки переведён на UIKit pan recognizer с проверкой
  направления и скорости, чтобы не конкурировать с вертикальным ScrollView.
- Динамический заголовок `Сегодня` получает прямые события границ секций через
  `onGeometryChange`, без нестабильного общего preference-pass.
- Четыре иконки нижних вкладок рендерятся в общем canvas `32×32 pt` через
  `resizable + scaledToFit`; одинаковый `font(pointSize:)` не использован,
  потому что intrinsic bounds SF Symbols `calendar`, `house`,
  `calendar.badge.clock` и `message` различаются. Центральная красная кнопка
  остаётся отдельным действием размером `44×44 pt`.

## Ограничение измерений

Шаблоны Instruments `Animation Hitches` и `SwiftUI` не поддерживаются на
iOS Simulator в текущей конфигурации Xcode, поэтому численные hitch-метрики из
Simulator не заявляются. Проверка включает реальные drag-жесты в Simulator,
сборку для физического устройства и unit-регрессии. Для окончательных FPS/hitch
цифр записывайте Instruments-трассу на подключённом iPhone.
