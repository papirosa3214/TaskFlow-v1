# Постоянные папки ролей TaskFlow — план реализации

**Цель:** чат запускается в постоянной папке роли, задачи сохраняют рабочую папку проекта. AGENTS.md, skills и scripts берутся из папки роли в обоих случаях.

**Согласовано:** Максим выбрал этот вариант 01.10.2026. Реализация в текущей сессии, без повторного согласования архитектуры. Разработка на Маке; выкладка на .110 отдельно по правилам INDEX.md.

**Устройство:** `TASKFLOW_ROLES_DIR`, по умолчанию `~/taskflow/roles/<role_key>/`. Стабильные ключи из реестра ролей, включая добавляемые владельцем. В каждой папке AGENTS.md, skills, scripts, workspace. credentials, routing и API permissions остаются у сервера. Рабочая папка чата — workspace; папка инструментария — его родитель. Задачи сохраняют проект/worktree.

**Технологии:** TypeScript, Pi SDK 0.84, Vitest, Python wrappers для существующих серверных инструментов.

## Границы и проверки

- Не менять iOS и права API; не переносить credentials.
- Новая роль получает папку без ручного изменения списка в коде.
- Повторная подготовка не перезаписывает AGENTS, навыки и пользовательские скрипты.
- Чужая роль и глобальные ресурсы Pi не подмешиваются в запуск.
- Существующие chat session IDs продолжаются после смены cwd: lookup в прежнем каталоге sessions без удаления истории.
- Режим plan сохраняет запрет записи.
- Каталог контекста показывает только ресурсы выбранной роли и отражает удаление файлов.
