# Linear → редактируемый командный план

## Согласованный сценарий

После подтверждения импорта владелец открывает обычную карточку TaskFlow. В существующем разделе командной работы уже есть черновик: можно изменить роль и результат шага, добавить участника, затем утвердить план существующим действием карточки. До утверждения роли не запускаются.

## Реализация

Импорт вызывает общий autoProposeCollaborationPlanIfNeeded после записи всех карточек, родителей и зависимостей. Это тот же механизм proposalFor → createDraftPlan, который используется обычным созданием карточки и предложением плана. Новый редактор и отдельный формат плана не создавались. Даже простой активной импортированной карточке предлагается одиночный исполнитель, которого владелец может заменить или дополнить.

Для листовой карточки используются действующие шаблоны по названию/описанию. Это шаблонное предложение, а не новый AI-разбор содержания Linear. Внешний исполнитель не назначает внутреннюю роль. Используются включённые внутренние роли. Если часть ролей шаблона выключена, предлагается один доступный исполнитель: удаление промежуточной роли не должно превращать последовательную цепочку в неподтверждённую параллельную работу. При отсутствии всех включённых ролей план не создаётся.

Для карточки с существующими детьми предлагается сводный результат: собрать и проверить их результаты, явно отметить недостающие. Дочерние карточки не превращаются в новые шаги родителя. Их планы утверждаются отдельно; утверждение родителя не запускает дочерние планы автоматически. Родительская роль должна пользоваться существующей иерархией. Никаких новых дочерних карточек или шагов исполнения при импорте нет.

Черновик создаётся от имени импортирующего владельца и внутри той же транзакции, что импорт. Повторный импорт не заменяет существующие черновики, утверждённые планы или историю отменённого предложения. Рабочая карточка (agent_state/ready_for_pickup) и завершённая карточка нового плана не получают. Для ранее импортированной активной карточки без истории планов предложение появится при следующем импорте.

## Проверка

35 тематических серверных тестов PASS; полный набор — 797 тестов в 107 файлах PASS. Проверены: отсутствие шагов исполнения до утверждения, доступность плана через обычный endpoint карточки, добавление участника тем же ops API, сохранение этой правки при повторном импорте, единственный черновик, сводный план родителя без копий детей, завершённые карточки и сохранение утверждённого плана. TypeScript build PASS.

Нативный редактор уже поддерживает draft и операции изменения; его код не менялся. Текущая проверка проводилась через серверные API на тестовых данных. Live Linear по-прежнему не подключён, .110 не обновлялся, реальные карточки не менялись.

## Границы

Запуск — только существующее утверждение владельцем. Обратной записи в Linear нет. Черновик — предложение для проверки и правки, а не утверждение о том, что внешние агенты ещё не сделали работу. Состояние источника, комментарии и история остаются в карточке для этой проверки.
