# Notifications Backend — рабочая документация

> **Статус:** рабочая документация, обновляется при любом изменении.
> **Дата начала:** 2026-09-27.
> **Владелец:** Maksim.

## Что это

Отдельный контур уведомлений, который пришёл на замену старого n8n → tg-relay
каналу. Все автоматические/полуавтоматические службы `.110` шлют сюда
свои сводки; сводки хранятся в файлах; **TaskFlow сам** создаёт
диагностические карточки по тревогам и дописывает результаты; iOS-приложение
читает сводки через HTTP API.

## Контурная схема

```
                                       ┌────────────────────────────────┐
                                       │ TASKFLOW SERVER (всё внутри)   │
                                       │ 192.168.1.110:3001              │
                                       │                                │
      ┌──────────────┐                  │  inboxTriageWatcher.ts          │
      │ Эмиттеры     │                  │    polling inbox/_diagnostic/* │
      │ .110:        │ alert_send.send  │          ↓ INSERT INTO tasks   │
      │ - autonomy   │ ─────────────→   │                                │
      │ - kb-add     │                  │  inboxResultsWriter.ts          │
      │ - runaway    │                  │    polling task_events          │
      │ - 9 других   │       ↓         │          ↓ appendBlock(md)    │
      └──────────────┘  rendezvous.write                                │
                          ↓                              ↓                │
                          ┌──────────────────────────────┐                │
                          │ ~Проекты/taskflow-уведомления │                │
                          │ ├── inbox/YYYY-MM-DD/*.md     │                │
                          │ ├── inbox/.../_diagnostic/*    │                │
                          │ └── archive/                  │                │
                          └──────────┬───────────────────┘                │
                                     │                                    │
                            notifications-api (5198)                      │
                                     │                                    │
                                     ↓                                    │
                          ┌──────────────────────────────┐                │
                          │   iOS приложение (Mac)       │                │
                          │   /Обзор → Уведомления        │                │
                          │   tf://task/<uuid>            │                │

```

**Нет внешних процессов-создателей карточек.** Правило Maksim 27.09.2026.
Всё происходит внутри долгоживущего процесса TaskFlow-сервера.

## Ключевые правила (НЕ менять без согласования с Maksim)

1. **Формат сводки не менять** — он зафиксирован в `file-format.md`.
2. **Карточки в TaskFlow создаёт только сам TaskFlow** — никаких внешних
   HTTP/Hermes/cron-вызовов к `/api/tasks` для создания карточек.
3. **Внешние сервисы только ПИШУТ** в `~/Проекты/taskflow-уведомления/inbox/`.
4. **Карточка-тикет уведомления — НЕ задача** — отдельный объект в БД.
5. **Inline-кнопок нет** — действия идут через стандартный workflow TaskFlow
   (claim → работа → review) и комментарии к проблемной карточке.
6. **Telegram-канал — резерв подтверждения** — основной путь это файлы +
   HTTP API для приложения.
