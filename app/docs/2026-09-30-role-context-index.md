## Что подтверждено сейчас

На iOS есть RoleRuntimeContextSheet, DTO, вызов API и действие редактора роли; изменения остались в рабочей копии под LOCK-268. Шесть вкладок: «Роль», «Общее», «Задача», «План», «Чат», «Границы». Представление read-only.

Серверная реализация c0f9bbc находится в ветке codex/role-runtime-context-visibility. Коммит не является предком текущего main; ранее выложенный на .110 main содержит переносы выгрузки и планировщика, но не этот endpoint. Предыдущие результаты тестов в спецификации исторические, в этом проходе не повторялись.

Graft iOS: сохранённый индекс STALE; запрос автоматически обновил структуру затронутых файлов, концептуальные резюме требуют обновления. В Mac-копии сервера wiring graph отсутствует; после неудачных графовых запросов прочитаны конкретные исходники сборки промптов.

## Источники для полного охвата

| Источник | Где применяется | Что показывать |
| --- | --- | --- |
| roles.prompt и scripts/role-prompts/<role>.md | Личность роли | Эффективную инструкцию, приоритет DB/fallback |
| LOCAL_EXECUTION_POLICY | Задачи и чат | Общую текстовую политику |
| defaultTaskPrompt | Первый запуск обычной задачи | Шаблон задания и AGENT_RULES |
| planSubtaskPrompt | Узел совместного плана | Инструкцию своего шага и артефакта |
| resumePrompt | Продолжение задачи | Инструкцию повторного захода |
| reviewPromptFor | Проверяющий | Правила проверки и вердикта |
| replyPrompt | Ответ на комментарий по сданной задаче | Правила ответа без продолжения работы |
| deliverAgentReply | Чат с ролью | Постоянную обёртку, правила включения истории |
| TaskContext / Python bridge | Контекст задачи | Источники задачи, комментариев, знаний и памяти; политика сборки |
| dependencyContext и collaborationPlanContext | Зависимости и план | Правила добавления артефактов предшественников |
| repoNote / projectRepo / roleWorkspace | Рабочая среда | Источник каталога, ветки и защиты чужих файлов |
| SessionManager и чат-сессии | Продолжение разговора | Правила хранения и повторного использования истории |
| taskflowTools, встроенные tools, resourceLoader | Возможности модели | Реально подключённые инструменты; фактическое подключение skills/AGENTS |
| agentState / access / roleRunAccess | Серверные ограничения | Ограничения, которые действуют независимо от текста инструкции |

Таблица — перечень охвата, не готовый контракт новых вкладок. Точные тексты динамических enrichers и специальные пути Секретаря требуют следующей сверки; не объявляем шесть прежних вкладок полным контекстом всех запусков.

## Нерешённая граница

Владелец подтвердил редактор всех действующих текстовых слоёв, включая общие и режимные правила. Прежнее read-only ограничение больше не соответствует задаче. Новые product-изменения пока не выполнялись; подготовлен проект расширенного редактора. Жёсткие серверные ограничения отображаются отдельно от текстовых инструкций, чтобы пользователь понимал, что правка промпта не меняет авторизацию.
