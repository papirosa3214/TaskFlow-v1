# Система и диагностические карточки — 27.09.2026

## Утверждённое поведение

Владелец подтвердил один переключатель «Система»:
- ВКЛ: автоматические допуск, назначение и запуск новых задач.
- ВЫКЛ: автоматических запусков нет; владелец может явно запустить выбранную задачу.
- Уже работающий агент заканчивает текущий заход; автоматическое продолжение при ВЫКЛ не запускается.
- «Автоодобрение задачи» удалено из приложения. «Авторевьюер» остаётся настройкой маршрута проверки.

## Реализовано

Сервер использует `users.task_intake_mode` канонического владельца как единое разрешение: automatic/manual. `/api/agent-service` сохраняет и читает это значение. Запуск встроенного worker больше не зависит от состояния старого `taskflow-trigger.service`.

Явное действие владельца записывается в durable queue как `manual_start=1` (миграция 067). Runtime допускает его при ВЫКЛ только для владельца и причины assigned; автоматические задания и действия роли не получают обхода. Ручные пути карточки и черновика передают этот признак.

Watcher допускает диагностические карточки при ВКЛ, вызывает существующий подбор роли/диспетчер и повторяет отказ без создания дубля. Новые карточки создаются с пустым agent_state, поскольку todo не является стартовым состоянием runtime.
