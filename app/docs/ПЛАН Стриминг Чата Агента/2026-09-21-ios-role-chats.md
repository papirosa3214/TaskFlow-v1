# LOCK-192 · Чаты с ролями на iOS

Дата: 21.09.2026. Основа — [план стриминга чата агента](ПЛАН%20Стриминг%20Чата%20Агента/IMPLEMENTATION-PLAN.md), этап 8 (первая половина).

## Сделано

- В старом экране «Чат» добавлен переход «Чаты с ролями». Старые каналы и экран не менялись.
- Список показывает название, участников и последнее сообщение из `GET /api/chats`.
- Создание чата выбирает учётки ролей из `GET /api/roles`: одна роль даёт `direct`, несколько — `group`; название необязательно.
- Экран чата загружает участников и историю, показывает имя и аватар автора, отправляет текст. Пока экран открыт, история обновляется раз в четыре секунды.
- В клиенте есть методы чтения чата, истории, отправки и добавления/удаления участников. Управление составом в UI в этом этапе не добавлено.

## Проверка

- `xcodegen generate` — успешно.
- `xcodebuild -project TaskFlow.xcodeproj -scheme TaskFlow -configuration Debug -destination 'platform=iOS Simulator,id=ED3C7DF7-F895-45B6-8A28-F67C02362103' -derivedDataPath /tmp/taskflow-lock192-derived build` — BUILD SUCCEEDED.
- Приложение установлено и запущено в iPhone 17 Pro Simulator. Кадр запуска: `outputs/lock-192/launch.png` (экран «Обзор»).

## Не проверено

- Переход к новым чатам и создание/отправка сообщения в живом UI: доступный инструмент не управлял окном Simulator. Кадр запуска подтверждает только запуск приложения.
- Ответ роли не проверялся: серверный этап 1 сохраняет сообщение, онлайн-ответ Pi запланирован следующим этапом.
- Адресация роли в группе, индикатор «думает», «Собрать задачу» и управление участниками в UI — следующие части этапа 8 после соответствующих серверных методов.

## Граница изменений

Серверный репозиторий не менялся. Незакоммиченные `project.yml`, `VoiceMessageLab/**`, `VoiceMessageLabTests/**` сохранены без правок.
