# Things 3 ↔ TaskFlow

Синхронизация запускается вручную в нативном приложении: **Настройки → Интеграции → Things 3 → Синхронизировать сейчас**.

На MacBook работает пользовательский LaunchAgent `com.taskflow.things-bridge`, который слушает `http://192.168.1.128:8765`. Он не запускает синхронизацию сам: `POST /sync` выполняет ровно один проход.

Мост читает только проекты Things в области `TaskFlow` и обращается к API TaskFlow на `192.168.1.110:3001`. Связь задачи хранится в заметке Things строкой `TaskFlow ID: <uuid>`. Проекты и задачи не удаляются автоматически; повторный запуск идемпотентен.

При первом запуске macOS может попросить разрешение **Настройки системы → Конфиденциальность и безопасность → Автоматизация → Things 3** для `/usr/bin/osascript` или пользовательского bridge.

Проверка с MacBook:

```sh
curl http://192.168.1.128:8765/health
curl -X POST http://192.168.1.128:8765/sync
```

Сервис и скрипты лежат в `Tools/`. После изменения пути проекта LaunchAgent нужно перезагрузить командой `launchctl bootstrap gui/$(id -u) Tools/com.taskflow.things-bridge.plist`.
