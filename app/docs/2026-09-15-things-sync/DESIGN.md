# TaskFlow ↔ Things 3 Manual Sync Design

## Goal

Добавить ручную двустороннюю синхронизацию проектов области `TaskFlow` в Things 3 с задачами TaskFlow по кнопке в экране интеграций.

## Scope

- Синхронизация запускается только явно кнопкой «Синхронизировать сейчас».
- Учитываются только проекты Things, находящиеся в области `TaskFlow`.
- Создаются недостающие проекты и задачи; повторный запуск не создаёт дубликаты.
- Синхронизируются название, описание, календарная дата и статус завершения.
- Удаление не зеркалится автоматически.
- MacBook выполняет AppleScript для Things и обращается к `http://192.168.1.110:3001`.

## Architecture

Нативное приложение вызывает локальный bridge-команду на MacBook. Bridge читает Things через AppleScript, получает TaskFlow-задачи через API, применяет детерминированный merge и записывает изменения обратно в Things. Стабильный идентификатор Things хранится в заметках задачи как `TaskFlow ID: <uuid>`; это позволяет повторному запуску находить связь без изменения схемы TaskFlow API.

Синхронизация запускается из `IntegrationsScreen` через `Process`/SSH-команду Mac bridge. Результат возвращается как JSON с числами imported/exported/updated/skipped/errors и показывается пользователю.

## Safety

- Bridge не удаляет проекты или задачи.
- Ошибка отдельной задачи не прерывает весь запуск; она попадает в счётчик ошибок.
- Токен URL Things не используется для чтения: AppleScript работает через разрешение Automation macOS.
- Секреты не записываются в репозиторий.
