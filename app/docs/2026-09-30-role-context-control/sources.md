# Источники контекста ролей — фактическая карта

Проверено по Mac checkout TaskFlow Server и установленному `@earendil-works/pi-coding-agent`, 30.09.2026. Graft CLI в этом окружении отсутствует; карта построена по ограниченному поиску исходников и вызовам runtime. Тексты секретов и временных пропусков в каталог не входят.

| Источник | Где входит в модель | Управление в «Команде» |
| --- | --- | --- |
| `roles.prompt` или `scripts/role-prompts/<роль>.md` | Задача, чат, ответ, ревью | Блок «Инструкция роли»; действующее хранилище `roles.prompt` |
| `AGENT_RULES`, `LOCAL_EXECUTION_POLICY` | Старт задачи, инструменты правил, чат | Общий или личный текст; права и переходы состояний остаются в коде |
| `task.start`, `task.resume`, `task.plan`, `task.reply`, `task.review`, `task.documentation` | Соответствующие заходы задачи и узла плана | Отдельные шаблоны с проверяемыми подстановками |
| `chat.wrapper`, `secretary.chat` | Обычный чат и чат Секретаря | Отдельные блоки; история сообщений остаётся динамическими данными |
| `secretary.summary`, `owner.task_intake`, `owner.extract_tasks`, `ai.subtasks`, `ai.structure` | Модельные операции Секретаря и постановки | Отдельные блоки; существующие настройки владельца остаются в `user_ai_prompts` |
| `secretary.voice`, `secretary.greeting` | Новая голосовая сессия через Unix bridge | Отдельные блоки, снимок при начале звонка |
| `mcp.initialize`, описания `tool.mcp.*` | Pi/MCP чат | Снимок на запуск; имена, схемы и обработчики неизменны |
| Описания `tool.runtime.*` и семи `tool.builtin.*` | In-process задачи и Pi чат | Отдельные блоки; доступность инструментов определяется кодом/профилем |
| Выбранные SDK `AGENTS.md`, `CLAUDE.md`, `SYSTEM.md`, `APPEND_SYSTEM.md`, skills | Pi чат | Активные файлы выбирает SDK с учётом доверия к проекту; сервер делает снимок текста на запуск. Исходные файлы не переписываются |
| Pi extensions, prompt templates, system prompt/compaction, model policy, tool schemas, allowlist, ACL | Pi и серверный runtime | Показаны как источник/ограничение. Код extensions, встроенное сжатие, схемы и права текстовым редактором не меняются |
| Карточка, комментарии, узел плана, найденные KB/память, сохранённая сессия | Динамический контекст конкретного хода | Источники показаны, содержимое конкретного запуска здесь не редактируется |

Эффективный текст выбирается так: правка роли → общая правка → исходный текст. Личность роли и два существующих owner prompt используют прежние таблицы, поэтому второй конкурирующей копии для них нет. Каждая новая ревизия имеет автора и запись истории; сброс убирает переопределение и возвращает наследование.

На live `.110` прочитано без записи: семь стандартных ролей используют fallback-файлы (поле `roles.prompt` пустое), у Секретаря задан отдельный текст в `roles.prompt`. Файл `synthesizer.md` также существует, но такой активной роли в live-таблице нет. Профиль Pi Исследователя содержит `taskflow_report`; внутренний запуск раньше не давал этот инструмент, исправление включено в ветку.

Manifest постоянных инструкций содержит id блока, источник, ревизию и SHA-256 текста. В уже запущенной Pi-сессии/звонке прежние инструкции и история могут продолжать влиять на ответ; новый текст берётся при следующем запуске/ходе. Полный инспектор содержимого конкретной сессии не входил в этот этап.
