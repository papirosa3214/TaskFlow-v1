# Эталонные скриншоты веб-версии TaskFlow

Снято 31.08.2026 с живого https://192.168.1.110:5180 под учёткой владельца
(сессия из `scripts/auth-state.json`, файл не менялся — md5 совпадает
до/после). Вьюпорт **420×912pt, deviceScaleFactor 3 → 1260×2736px** —
реальный экран iPhone владельца (см. `native/spec/DESIGN-TOKENS.md`,
MEMORY.md), а не 390×844 из `scripts/screenshot.mjs` — тот харнесс собран
под другую задачу (прицельная проверка одного экрана после правки), для
набора «эталон под нативное приложение» размер взят намеренно другой,
ровный.

Браузер — системный Chrome (`channel: "chrome"`) через playwright из
`node_modules` самого репозитория; путь `chromium-1228` + `playwright-core`
из старого урока `taskflow-screenshot-playwright.md` не использован —
харнесс `scripts/screenshot.mjs` уже заменил эту схему (см. комментарий в
начале файла), это подтверждено в сессии живым запуском. Код проекта не
менялся, сервисы не перезапускались, задачи/данные не создавались — только
просмотр, переходы кликом по существующим строкам списков и один клик
«вкл/выкл» на переключателях фильтра, который живёт только в localStorage
эфемерного браузерного контекста этой сессии (закрылся вместе с браузером,
на сервер/реальный аккаунт Максима не влияет — подтверждено чтением кода
`src/store/index.ts`, `plannerVisibleProjects` персистится через zustand
`persist` в localStorage конкретного origin/браузера, не через API).

Скрипты сбора существовали только в скретчпаде текущей сессии (эфемерная
папка, живёт до конца сессии) — в репозитории их нет.

## Что не идеально (и почему)

- **`today.png`** — в момент первой съёмки на `/today` был пустой экран
  («Под выбранные фильтры ничего не подошло»): в этой свежей сессии
  плейбека opt-in список проектов ежедневника (`plannerVisibleProjects`,
  чипы под шапкой) был пуст по умолчанию — это НЕ фильтр из
  `TaskFilterSheet` (его сброс не помог бы, проверено чтением кода) и не
  испорченные данные, а стандартное состояние свежего браузерного
  профиля. Включил в фильтрах 3 проекта («AI Control Center», «TaskFlow -
  NewTodoist», «Домашний сервер») и переснял — итоговый `today.png`
  показывает реальные карточки задач. Изменение живёт только в
  localStorage закрывшегося playwright-контекста, реальную сессию
  Максима не затрагивает.
- **`note-editor.png`** — первая заметка, до которой дошёл клик, оказалась
  пустой («Пишите здесь что угодно…», статус «Сохранено»). Раскладка
  редактора (тулбар B/I/U, заливка, ссылка, H1–H3) видна полностью, просто
  без содержимого.
- **`inbox-timeline.png`** — реальный аккаунт содержит десятки тестовых
  задач «shot-$i» (похоже на баг чужого скрипта с неподставленной
  переменной). Не трогал их (задание — только просмотр), но стоит
  отдельно показать Максиму — это видимый мусор в проде.
- **`agents.png`** — с первой попытки `page.screenshot()` подвис на этапе
  ожидания шрифтов и словил таймаут; со второй попытки (свежая загрузка)
  снялся штатно.

Экраны, которые оговорены в задаче как «плюс, если удастся» (карточка
задачи, задачи проекта, задачи метки, редактор заметки) — удалось получить
все четыре на реальных данных, ничего не пропущено.
